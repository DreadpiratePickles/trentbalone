## Discovery
- `trent setup` lives in `apps/cli/src/commands/groups/diagnostics.ts` (`setupSpec`, `runSetup`), not
  `configuration.ts`. The first-run path is `handleTopLevel` in `apps/cli/src/commands/index.ts:288-298`:
  it prints `theme.success("Setup complete: ...")` whatever `summary.success` says, then returns
  `EXIT.CONFIG` without a launch, so the REPL never opens.
- `setupSpec.run` returns `{ data }` with no `exitCode`, so a failed setup exits 0.
- The wizard prints through `ConsoleOutput` (`packages/trent-core/src/setup/ports.ts:58`), which writes
  straight to `process.stdout`, bypassing the command context: under `--json` the guidance lines land
  on stdout ahead of the JSON document.
- The REPL has no `boot*` file of its own; the boot test is `apps/cli/src/repl/__tests__/boot.test.ts`
  and the degraded banner is `apps/cli/src/repl/degraded.ts` (tested in `__tests__/degraded.test.ts`).
  `isDegraded` checks presence of provider key names only.
- `trent connect --help`: stripe, google (OAuth, Calendar), square, twilio, buffer, meta, bluesky. No
  model provider, so it is NOT the fix for a missing model key. The real path is: put a key in the
  environment or the profile env file, then `trent setup` (quick detects it); `trent setup --mode full`
  asks for one through a masked prompt.
- No-terminal refusals already have a house style: `EXIT.USAGE` (2) and "nothing here can answer a
  prompt" (`groups/workspace.ts:47`, `groups/connect.ts:124`). The errors module defines no TTY-specific
  code, so the no-terminal case exits 2.
- The keyless REPL: the planner falls back to a deterministic plan and the critic auto-passes, but the
  seat guard fails the run when every model call fails (`packages/trent-core/src/orchestrator/index.ts:219-224`).

- `trent setup --mode blank-slate </dev/null`: the inquirer select drawn, then
  `error: User force closed the prompt with 0 null`, exit 2.
- REPL driving: `\n` is Ctrl+J (a newline in the input), `\r` submits; there is no `/exit` command
  (`Unknown command: /exit`); stdin EOF ends the REPL. So the transcript driver is `printf '/help\r'`.
