  `<profile>/locks/writers/<pid>.lock` (shared, one per process, refcounted in process, label =
  distinct surfaces joined by `+`). Body `{ pid, startedAt, label, hostname }`, files 0600, dirs 0700.

  (pid reuse); unreadable = held for 5 s, then stale. Release: `release()`, `exit`, and SIGINT/SIGTERM
  only when this module is the sole listener (then it re-raises so the default kill still happens).
