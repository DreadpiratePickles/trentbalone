# 2026-09-18 — W2.0: wiring wave 1 into the surfaces a user touches

Task W2.0 (wave 2). Branch `feature/trent-fleet-v2`. No commits, no staging: the working tree is
shared with B2, C3, C4 and D0, whose in-flight edits are visible in every full-suite run below.

## What landed

1. **Workspace context into the prompt.** `apps/cli/src/runtime/headless.ts` now calls
   `loadWorkspaceContext({ cwd: workspace, profileDir, config })` before the fleet-memory hook is
   built and hands the rendered block to `wireFleetMemory({ workspaceContext })`, so every surface
   that goes through the headless runtime (REPL, `trent run`, gateway, cron, heartbeat) carries the
   trusted `AGENTS.md` / `CLAUDE.md` / `.trent/*.md` in the STABLE tier under
   `CONTEXT_BLOCKS.workspace`. `apps/cli/src/repl/workspace.ts` owns the wording and the notices;
   the REPL banner prints the untrusted instruction and one line per refused file. The runtime
   exposes the whole `WorkspaceContext` so a surface can say what was NOT loaded.
2. **Session hooks.** `runSessionHooks("session_start")` runs once the object graph is up and the
   company is ensured; `("session_stop")` runs first in `cleanup()`, once, on whichever exit path
   gets there. Skipped and failed hooks become `runtime.notices()`, merged with the live
   `tools.hookNotices` getter (`ToolWiring` now carries it), and the engine prints each distinct
   line once — at start-up and after every turn, because a tool hook is skipped during a call.
3. **`/context`.** `apps/cli/src/repl/context-report.ts` holds `ContextTracker` (which (run, seat)
   pairs happened, learned from the event stream) and the report over `hook.contextFor(runId, seat)`.
   The REPL command and the TUI pane render the same lines from the same function. The 80-percent
   pressure notice already rides the bus as `step_note`; the REPL renderer showed it, the TUI
   dropped it, and now shows it once per run.
4. **Decision 5.** `apps/cli/src/slash/` is deleted. `/fleet`, `/skills`, `/personality` and
   `/sessions` were merged into `repl/commands.ts` against live state through ports on
   `ReplContext`; the rest were dropped as duplicates, mutations that cannot affect a running
   session, or fabrications. `repl/output.ts` died with its only caller.
