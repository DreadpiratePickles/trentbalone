## Design decisions (and why)

1. **The operator.** A headless Trent run never auto-answers a hold, and every business write is floored, so a
   bench with no human would fail every write task for Trent and none for a harness without gates. The bench
   declares a scripted owner: a held call is approved when its tool is in the task's `approves` list, rejected
   otherwise, and every request is logged. It decides at Trent's tool seam (`bench/operator.ts`), which is the
   same seam for all three harnesses (Hermes calls the same adapters over MCP), and it replays exactly what a
   human's yes does in solo: `dryRun` (stamps the bound row with the preview) then `execute` in the same
   (run, step), so the row is granted by the step approval. No harness pays a model turn for an approval.
2. **Hermes gets Trent's tools over MCP** through the code behind `trent mcp serve --http`
   (`createTrentMcpServer` + `createMcpHttpServer`), bound on loopback in the bench process and serving the
   bench's tool build (fake endpoints). `trent mcp serve` itself serves the profile's real providers, which a
   bench must never touch. Hermes is restricted to that toolset (`-t mcp-trent`), so both sides have the same tools.
3. **Money.** The ledger is integer cents per run, rounded up once, so one flash-lite run is at least 1 cent and
   "<= 0.5 cents per successful task" could never be shown in whole cents. The bench reports the ledger's
   integer cents AND the list price re-derived from the ledger rows' token split in integer micro-cents
   (`priceCallMicroCents`, the unit the meter itself sums in, P2-8); the target is judged on micro-cents.
   Hermes reports tokens and no cost; its tokens are priced with the same table.
4. **Time to first token** is when the harness first shows model output: Trent solo, the gateway's first token
   frame (or its first completion when not streaming); the fleet, the first `plan_end`, `step_note`,
   `step_output` or `step_delta`; Hermes, the first `text` or `tool_use` line. Measured on the bench's clock.
