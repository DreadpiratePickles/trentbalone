Trent Fleet

One command installs the trent CLI into ~/.trent. No sudo, no Node, no Bun.

macOS and Linux

curl -fsSL https://agent.let-trent.uk/install.sh | bash

Windows (PowerShell)

irm https://agent.let-trent.uk/install.ps1 | iex

What the installer does

  • Downloads the binary for your platform from the GitHub Release, over HTTPS only.
  • Downloads SHA256SUMS and verifies its signature against a public key embedded in the script.
  • Checks the binary's SHA-256 against the signed sums before it is moved into place.
  • Writes ~/.trent/bin/trent and adds one PATH line to your shell profile.

Read the script before you run it: install.sh, install.ps1.

Verify a release by hand

minisign -V -p minisign.pub -m SHA256SUMS
sha256sum --check SHA256SUMS

Release assets and public keys: github.com/DreadpiratePickles/trentbalone/releases.
